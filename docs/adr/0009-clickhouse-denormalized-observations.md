# ADR-0009: Денормализация наблюдений в ClickHouse

Статус: принято (этап 0, 2026-10-08)

## Контекст

Раздел 5.2 ТЗ задаёт `obs_provider` и `obs_payment_method` без страны,
платформы и вертикали, но материализованное представление доли рынка по
месяцам должно группировать по этим полям без джойнов.

## Решение

В `obs_provider` и `obs_payment_method` добавлены `country`,
`platform_id`, `vertical_id` (LowCardinality), заполняемые на момент
наблюдения. `mv_market_share_monthly` агрегирует `uniqState(host_id)` по
(месяц, страна, платформа, вертикаль, провайдер).

## Последствия

Запросы отчётов не требуют джойнов; историческая принадлежность домена к
стране/вертикали фиксируется на момент скана, что корректно для истории
(FR-HI-*).

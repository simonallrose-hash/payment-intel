# ADR-0004: Сигнатуры PSP только из официальной документации

Статус: принято (этап 0, 2026-10-08)

## Контекст

Правила детекции нельзя выдумывать: ложное правило даёт ложные
срабатывания в B2B-датасете.

## Решение

Правило получает `enabled: true` только если его паттерн подтверждён
официальной документацией вендора (ссылка в поле `source`). Остальные
сигнатуры хранятся как `enabled: false, needs_verification: true` и
перечисляются в отчёте этапа. Загрузчик отклоняет `enabled: true` вместе с
`needs_verification: true`. Включение правила — отдельный коммит с
обновлённым `source`.

## Последствия

включены, 42 требуют проверки.

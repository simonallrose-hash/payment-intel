# ADR-0003: Значения для полей оплаты (FR-CW-14)

Статус: принято (этап 0, 2026-10-08)

## Контекст

Checkout-скан должен раскрыть список способов оплаты, иногда для этого
форма требует ввода в поля карты. Ввод реальных или сгенерированных номеров
недопустим (правило безопасности).

## Решение

`reference/test_payment_values.yaml` (этап 2) содержит только
опубликованные тестовые номера карточных схем/PSP и заведомо невалидные по
Луну номера. Генерация номеров в коде запрещена. Слой guardrails пропускает
в поле оплаты только значение, побайтно совпадающее с записью справочника, и
только при `allow_payment_field_fill=true`. Ввод делается, лишь если список
методов не раскрылся без него; факт ввода и возможной токенизации PSP пишется
в журнал скана. Кнопки оплаты и заказа не нажимаются никогда.

## Последствия

Подтверждено владельцем проекта 08.10.2026. Тест на «магазине-ловушке»
(AC-04) входит в этап 2.

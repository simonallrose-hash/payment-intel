# ADR-0002: Масштаб первой версии и модуль A

Статус: принято (этап 0, 2026-10-08)

## Контекст

ТЗ говорит о 347 млн доменов полного реестра и о модуле A как потребителе
данных, но целевой объём первой версии — 1 млн e-commerce доменов (9.4).

## Решение

Архитектура, партиционирование, TTL и расчёт ёмкости (`docs/capacity.md`)
делаются под 1 млн доменов. Модулю A оставлены только Python-интерфейсы
пакета `core` (модели, настройки, клиенты БД); UI и API модуля A в этапы
0–3 не входят.

## Последствия

Переход на полный реестр потребует только добавления партиций и
горизонтального масштабирования воркеров; схема данных не меняется.

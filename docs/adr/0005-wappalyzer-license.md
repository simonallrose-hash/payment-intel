# ADR-0005: Сигнатуры Wappalyzer

Статус: принято (этап 0, 2026-10-08)

## Контекст

Форк webappanalyzer содержит полезные сигнатуры платформ, но его лицензия
не проверена.

## Решение

Данные Wappalyzer в репозиторий не включаются до проверки лицензии.
Каталог `rules/wappalyzer/` содержит только README. Платформы детектируются
собственными правилами `rules/platforms/`. Загрузчик формата Wappalyzer без
данных — этап 2.

## Последствия

Покрытие платформ на старте ниже, зато без лицензионного риска.

# ADR-0006: Gold set не выдумывается

Статус: принято (этап 0, 2026-10-08)

## Контекст

ТЗ просит «первые 100 магазинов» gold set уже на этапе 0. Ручную разметку
реальных магазинов нельзя сгенерировать автоматически.

## Решение

На этапе 0 поставляются структура (`gold_label`), импорт CSV с upsert,
шаблон и синтетическая выборка `tests/fixtures/gold/*.csv` на доменах
`*.example` для тестов метрик. Реальные 100 магазинов размечает аналитик и
импортирует командой `payintel gold import`.

## Последствия

Подтверждено владельцем проекта 08.10.2026. Отклонение зафиксировано в
отчёте этапа 0; `make eval` на пустом gold set возвращает «not applicable».

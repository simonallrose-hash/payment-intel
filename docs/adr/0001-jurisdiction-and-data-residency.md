# ADR-0001: Юрисдикция и место хранения данных

Статус: принято (этап 0, 2026-10-08)

## Контекст

ТЗ 2.6 упоминает офшорную юрисдикцию оператора, а AS-05 и LR-11 требуют
хранения и обработки данных в ЕС. Противоречие нельзя разрешить без юриста
(LR-23).

## Решение

Выбирается консервативный вариант: код, настройки и compose рассчитаны на
хранение всех данных в ЕС. Регион S3 (`S3Settings.region`, по умолчанию
`eu-central-1`) и адреса серверов — параметры, без изменений кода. Любое
другое размещение возможно только после письменного заключения юриста.

## Последствия

Ничего в схеме не привязано к стране; `docs/legal/lia.md` и `ropa.md`
содержат пункты, которые юрист должен заполнить. Тесты не зависят от региона.

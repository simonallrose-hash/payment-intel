# ADR-0008: Регистрация аккаунтов в магазинах (FR-CW-12)

Статус: принято (этап 0, 2026-10-08)

## Контекст

Для раскрытия способов оплаты некоторые магазины требуют аккаунт. ТЗ 2.6
оставляет открытыми юридические вопросы о таких регистрациях.

## Решение

Регистрация реализуется на этапе 2 строго по FR-CW-12: только при
недоступном гостевом оформлении, только под `allow_account_registration`,
один аккаунт на магазин (`store_account`), пароль шифруется AES-GCM
(`core/crypto.SecretBox`) ключом из окружения, синтетические данные из
`reference/synthetic_identities/`. Список открытых вопросов — в runbook §8.

Обновление (долг 3, 2026-10-11, по ТЗ 2.6 и AS-25): флаг
`allow_account_registration` включён по умолчанию и является аварийным
выключателем, а не «разрешением после заключения юриста». При opt-out
аккаунт отключается автоматически (`AccountManager.delete`: статус
`deleted`, шифротекст стёрт, аудит `store_account.delete`), удаление на
стороне магазина — ручной шаг `staff_compliance` (runbook §17).

## Последствия

Регистрация работает с первого запуска; юридическое заключение (LR-23)
может потребовать её выключить — для этого достаточно флага без
перезапуска воркеров. Один аккаунт на магазин, повторный вход вместо
повторной регистрации, `newsletters=0`.

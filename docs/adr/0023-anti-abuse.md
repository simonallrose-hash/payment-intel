# ADR-0023 — Анти-абьюз: детекторы, инциденты, автоматическое ограничение, канарейки, квартальные отчёты

Статус: принято (этап 4). Связано: FR-AB-02…05, FR-EX-05, ADR-0016, ADR-0018.

## Решения

1. **Источник — журнал использования (`usage_log`).** Детекторы работают
   только по собственному журналу API (организация, эндпоинт, число записей,
   IP, статус, код отказа); никаких внешних сервисов. Окно 24 ч, базовая
   линия 14 окон.
2. **Пять детекторов** (`abuse.detectors`): доля отказов `outside_segment`;
   всплеск записей (> 3× среднего); перебор каталога (много
   `GET /v1/stores/{domain}`, почти все домены различны); новая сеть;
   зондирование полей (`field_profile_insufficient`). Критичными считаются
   только два самых сильных сигнала: записи > 10× среднего и перебор
   ≥ 3000 доменов.
3. **«Новая страна/ASN» заменена на «новая сеть /16».** База GeoIP/ASN в
   репозиторий не включается (лицензия, размер, актуальность); префикс /16,
   не встречавшийся у организации 30 дней, — наблюдаемый без внешних данных
   аналог. Если оператор подключил таблицу ip2asn (ADR-0025), детектор не
   меняется: он остаётся объяснимым без неё.
4. **Автоограничение — через entitlements.** Критичная находка ставит
   организации `restricted`; все её ключи получают 403
   `{"code":"forbidden","reason":"org_restricted"}` (ADR-0016: то же тело,
   что и прочие отказы по гранту). Снятие — только вручную при закрытии
   инцидента с `lift`; инциденты видит `staff_compliance`
   (`/admin/abuse`). Автоограничение отключаемо (`abuse.auto_restrict`),
   но включено по умолчанию: FR-AB-03 требует немедленной реакции.
5. **Канарейки замыкаются на экспорт.** Обращения к канареечным доменам
   (DNS у авторитетного резолвера, HTTP на catch-all, письмо) подаются из
   логов строками `<ts> <domain> [source] [detail]`; попадание связывается с
   экспортом, в который домен был подмешан (ADR-0018), и открывает `high`-
   инцидент. Сами логи система не читает — только то, что ей передали.
6. **Квартальный отчёт об использовании** собирается из журнала, экспортов,
   доставок алертов и инцидентов в XLSX (`usage/<org>/<period>.xlsx`) с
   JSON-сводкой в `usage_report`; отчёт виден клиенту на странице
   использования портала и в админке. Это не биллинг: сумм и тарифов в нём
   нет.

# Legitimate Interest Assessment (каркас, заполняет юрист — LR-23)

Статус: черновик. Обработка в продакшене не начинается до подписания.

## 1. Цель обработки
Сбор публично наблюдаемых технических сигналов платёжной инфраструктуры
сайтов e-commerce для B2B-аналитики (ТЗ 1, 2.1). Персональные данные не
являются целью; возможные случаи: контактные данные на страницах магазина,
данные аккаунта сканера (синтетические).

  (`RetentionSettings.raw_artifacts_days`).

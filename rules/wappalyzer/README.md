# Сигнатуры Wappalyzer / webappanalyzer

Каталог намеренно пуст (ADR-0005). Лицензия форка `webappanalyzer` должна
быть проверена юристом до включения его данных в репозиторий. Платформы
магазинов детектируются собственными правилами в `rules/platforms/`,
составленными по официальной документации вендоров. Загрузчик формата
Wappalyzer (без вложенных данных) появится на этапе 2 вместе с детектором.
